# xb: Xarı Bülbül in your terminal

An open coding agent for any model. It runs on OpenRouter (free models first), Ollama Cloud, local Ollama or LM Studio, and any OpenAI-compatible API.

```bash
xb                 # chat in the current folder
xb login           # save an API key in the OS keychain
xb -p "explain this repo" --output-format json
```

`xb` shares settings, chats, usage and keys with the [Xarı Bülbül desktop app](https://github.com/Parzival-Samanyolu/xari-bulbul).
- **Setup:** run `xb login`, or set `OPENROUTER_API_KEY`.
- **Help:** run `xb --help` for all options, and type `/help` inside the app.
