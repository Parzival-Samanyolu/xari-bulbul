# Third-party code in the xari CLI

The interactive UI uses components from **Gemini CLI**, Copyright 2025 Google LLC, licensed under
the Apache License, Version 2.0: https://github.com/google-gemini/gemini-cli. The copied and
modified files, and the full license text, are in `src/ui/vendor/gemini/`.

The bundle (`dist/xari.mjs`) also includes open-source packages from npm (Ink, React, lowlight,
highlight.js, chalk, string-width, strip-ansi, tinycolor2, tinygradient and the dependencies of
`@harness/core`); each keeps its own license, listed in its package.
