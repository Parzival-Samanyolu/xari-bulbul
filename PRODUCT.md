# Product

## Register

product

## Platform

web

## Users

Developers who find Xarı Bülbül on GitHub and install it as a desktop app on macOS, Windows or Linux. They use it while working in their own projects: they open a folder, ask the agent to read, change and run code, and review what it did. Many of them run free models and want to see exactly what each request uses. They picked an open-source tool on purpose, so they expect to adjust it, extend it and understand it.

## Product Purpose

Xarı Bülbül is a desktop AI coding agent that works directly in a project folder with any model: OpenRouter, Ollama Cloud, or any OpenAI-compatible provider. Its core jobs are to:
- carry out coding tasks with visible, reviewable steps (diffs, commands, permission prompts)
- make switching models a single action
- keep token, request and cost usage visible at all times

Success means a developer installs it from GitHub, makes it fit their own workflow, and trusts it enough to keep using it for real work.

## Positioning

The coding agent that is yours to shape. Settings, tools, slash commands and providers are all open to change, so the tool adapts to the developer instead of the other way round.

## Brand Personality

Calm, precise, crafted. The interface is quiet and unhurried, and nothing competes for attention with the work. Numbers, states and outcomes are exact, so there's no guessing what the agent did or what it cost. Small details are visibly made with care.

The name has **real character**. Xarı bülbül is a flower from Shusha in Karabakh, and that flower and its place shape the palette and small details. The product still reads first as a serious professional tool.

Reference points:
- Linear, for dense, fast, keyboard-first, relentlessly consistent UI
- Obsidian, for being a personal tool you customize and extend

## Anti-references

- A clone of Claude Code or Cursor: the standard dark-charcoal-plus-orange AI coding tool look.
- A SaaS dashboard: cards everywhere, gradients, big metric tiles, marketing gloss.
- A hacker terminal: green-on-black, neon, retro-terminal cosplay.

## Design Principles

- **The work is the hero.** Code, diffs and the agent's actions get the space and contrast. Chrome recedes.
- **Show the truth, precisely.** Tokens, requests, cost, context and permissions are always exact and always visible, never vague or hidden.
- **Open by design.** Every customization point should be discoverable, and it should feel like part of the product rather than a hidden power-user corner.
- **Identity through restraint.** The flower's character comes through in color and a few crafted details, not ornament. It's a serious tool with a sense of place.
- **Keyboard-first consistency.** Every common action has a fast path, and every screen speaks the same visual vocabulary.

## Accessibility & Inclusion

WCAG 2.2 AA: text contrast of at least 4.5:1 (3:1 for large text), full keyboard operation, and visible focus on every interactive element.
